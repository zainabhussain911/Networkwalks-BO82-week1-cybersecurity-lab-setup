# Networkwalks-BO82-week1-cybersecurity-lab-setup
Cyber security lab setup 
I created a cyber security lab setup in virtual box. I followed the steps that I mentioned below:
Firstly I allowed virtualization on laptop by visiting Bios setting.
Then I installed 7_zip tool so that I can unzip the Kali linux zip file.
I installed 7_zip tool from its official website i.e https://www.7-zip.org/download.html
After that I downloaded and installed the virtual box from the official website i.e https://www.virtualbox.org/wiki/Downloads
Then I installed the pre built virtual box machine of kali linux from its official website that is get kali.
After installation of virtual box then I created a Nat-network in it and assigned a static ip address to it.
Then I created Kali linux vm in virtual box.
Then I allocated it resources to this vm.
I checked its ip address by using command "ifconfig"
